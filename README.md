# SuperShowroom — Landing Page

Static, dependency-free landing page for [SuperShowroom](https://www.supershowroom.in) by Viral Inbound.

- `index.html` — markup
- `styles.css` — light theme design system
- `script.js` — nav, reveal animations, feature tabs, year-one cost calculator
- `assets/images/` — optimised WebP imagery

Run locally: `python -m http.server 5178` and open http://localhost:5178

Deploys as a static site on Vercel (no build step).
